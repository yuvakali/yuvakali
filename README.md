## 🚀 Flagship Project — SpaceTug Orbital Simulator (STOS)

A **real-time 6-DOF orbital mechanics laboratory** for spacecraft servicing:

- **Orbital Transfer Engine** — Hohmann, Bi-elliptic, Lambert targeting, low-thrust Edelbaum spirals, J2 maneuvering.
- **Rendezvous & Proximity Operations** — Clohessy–Wiltshire relative dynamics, V-bar/R-bar corridors, NMC, collision avoidance.
- **Autonomous Inspection & Robotic Capture** — multi-spectral sensor fusion + AI gripper-point scoring.
- **Stack** — C++17 core · Python/NumPy/SciPy physics · React + Three.js · Electron desktop.

> **Note:** The `stos-trial` and `stos-trial-releases` repositories are licensed by SPACETUG Private Limited.

## 🧠 Other Highlighted Work

### 🛰️ AURA-Space — Advanced Fiducial Marker System
Custom, space-grade fiducial markers for robotics & autonomous navigation using **BCH[15,5,7] error correction**, QPSK pilot rings, and real-time contour-based detection (OpenCV).

### 📊 IMU-MEKF — Attitude Estimation
Real-time **Multiplicative Extended Kalman Filter** fusing BNO055 IMU data (gyro/accel/mag) over serial with an Arduino — includes outlier gating and Joseph-form covariance updates.

### 🎯 Computer Vision & Perception
- **YOLOv8 custom segmentation** and object-detection pipelines.
- **ArUco / fiducial marker** detection and pose estimation.
- **LiDAR point-cloud viewer** and 3D sensor tooling.
- Real-time **debris tracking** with object trackers.

### 🤖 Robotics & Simulation
- **ROS2 + Gazebo** simulation for Universal Robots.
- Space robotics concepts in **Rust**.
- Reinforcement learning for control systems.
