### 🌌 SpaceTug Orbital Simulator (STOS)
> Real-time **6-DOF** orbital mechanics laboratory for spacecraft servicing, rendezvous & proximity operations (RPO), and autonomous robotic capture.

| Capability | Details |
|---|---|
| 🧭 **Orbital Transfer** | Hohmann · Bi-elliptic · Lambert targeting · Edelbaum spirals · J2 maneuvering |
| 🤝 **Rendezvous & RPO** | Clohessy–Wiltshire · V-bar/R-bar · NMC · collision avoidance |
| 🔬 **Inspection & Capture** | Multi-spectral sensor fusion · AI gripper-point scoring |
| ⚙️ **Core Stack** | C++17 · Python (NumPy/SciPy) · React + Three.js · Electron |

### 🔲 AURA-Space
> Space-grade **fiducial marker system** for robotics, drones & autonomous navigation — engineered for reliable detection under extreme rotation, zoom, dim lighting, and dynamic motion.

| Feature | Detail |
|---|---|
| 🧩 **Error Correction** | BCH[15,5,7] — corrects up to 3-bit errors |
| 🔄 **Rotation Invariant** | Full 0°–360° via QPSK pilot ring |
| 📷 **Multi-scale Detection** | Concentric orbit rings + STag fallback |
| 🧠 **Tracking** | Temporal motion-model tracker |
