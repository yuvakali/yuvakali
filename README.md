## 🔲 › AURA-SPACE

> Space-grade **fiducial marker system** for robotics, drones & autonomous navigation.

Built on **BCH[15,5,7] error correction**, **QPSK pilot rings**, and real-time computer vision (OpenCV) — designed for reliable detection under extreme rotation, zoom, dim lighting, and dynamic motion.

| Feature | Detail |
|---|---|
| 🧩 **Error Correction** | BCH[15,5,7] — up to 3-bit correction |
| 🔄 **Rotation Invariant** | Full 0°–360° with QPSK pilot ring |
| 📷 **Multi-scale Detection** | Concentric orbit rings + STag fallback |
| 🧠 **Tracking** | Temporal motion-model tracker |
